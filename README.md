# Adrishya
Adrishya is an AI-powered assistive navigation system designed to help visually impaired people understand their surroundings and navigate more safely and independently.
The Adrishya website prototype was developed using Lovable, an AI-powered software development platform, with AI-assisted development used to build and integrate the website's interface and functionality.
The system uses a camera to detect people, vehicles, bicycles, obstacles, hazards, and stairs. It analyzes the surroundings and provides useful safety information through voice guidance, such as warnings about obstacles, stairs, approaching vehicles, or directions to move left or right.
Adrishya also integrates real-time GPS and OpenStreetMap-based navigation, allowing users to detect their current location, enter a destination, view a route, and receive navigation instructions.
Main Features
AI-based object and hazard detection
Stair detection for stairs going up/down
Object tracking and risk assessment
Left, center, and right path analysis
Voice-based safety guidance
Crowd detection
Real-time GPS location
OpenStreetMap-based navigation
Destination and voice navigation
Heart-rate monitoring prototype
Emergency contact and SOS with location sharing
Live camera and video testing
# Development
The current project is a website-based prototype created with Lovable using AI-assisted development. It is designed as a working demonstration of the Adrishya concept, with the architecture intended to support future integration with physical hardware such as cameras, ultrasonic sensors, vibration motors, and health sensors.
Goal: Adrishya aims to combine AI perception, navigation, safety guidance, and emergency assistance into one accessible system to support safer and more independent mobility for visually impaired people.
